From a prompt to a place.

Generate an independent 3D scene with WorldExplorer. Jobs run on your selected LRZ allocation and retain panoramas, trajectory videos, training outputs and exported Gaussian splats on DSS.

Generate a scene

Manual mode creates 4 fixed views and 88 candidates for each of 4 gaps. Choose one per gap in any order; all candidates are generated beforehand. Then expand the 8-image panorama. Automatic and fast modes run the full pipeline unattended. Use the GPU exclusively.

Prepare once. Return later.

  1. Select a running reservation on Compute and connect SSH.
  2. Prepare the isolated runtime. SEVA weights and authentication reuse OracleGS’s account cache. FLUX access is required.
  3. Generate, then refresh until startup is confirmed. In manual mode, wait for the candidate gallery to synchronize and choose four inpainted views before expanding. The laptop may sleep while remote work runs.
  4. Reconnect VPN + SSH tomorrow and restart the dashboard. Finished results synchronize automatically, then verified remote run files are removed.

First setup installs dependencies and additional depth models. It does not generate a scene. Reservation expiry still stops GPU work.

Generation runs

While this page is visible, remote jobs are checked once per minute. Startup and new submissions also trigger a check. Finished runs synchronize automatically, then verified DSS run files are removed. Offline results stay on DSS; shared models and environments stay reusable.
